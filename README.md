# Master's Thesis

This repository contains the research materials for the Master's thesis in Environment and Development at the Universidad Nacional de Colombia, Medellín, Facultad de Minas, by **Oscar Ivan Sanchez Patiño**.

## Thesis title

**Definition of spatio-temporal rainfall thresholds for landslides in the Aburrá Valley**

## Repository structure

| Folder | Description |
| --- | --- |
| `src/` | Analysis scripts and notebooks, organized by chapter from `01_Chapter` to `06_Chapter`. |
| `data/` | Input data, processed datasets, and metadata. |
| `results/` | Figures, tables, maps, and other analysis outputs. |
| `manuscript/` | LaTeX files, figures, and references for the manuscript. |
| `info/` | Folder for research notes and background information. |
| `doc/` | Folder for code and project documentation. |

## Data access

For rainfall data, consult **SIATA** or **EPM**, or email them directly to request access.

For landslide data, consult **DAGRD** or **GEOHAZARDS**.
